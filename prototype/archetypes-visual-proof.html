Belcanto mobile archetypes

Exploratory high-fidelity composition proof. All people, dates and lesson details below are explicitly fictional fixtures. No screen is a product requirement.

Focused stress proof

200% text / 320 px

Media is removed before essential context. Bottom navigation may switch to a platform overflow pattern. Primary action remains reachable and no fixed-height text container is allowed.

Sparse / corrected evidence

“Пока есть одна запись” replaces an empty chart. Correction shows old value, new value, author, date and reason; it never silently rewrites history.

Revoked consent

Community media becomes a neutral surface. Event name, organiser, capacity and participation action continue to work without identifying the person.

Offline / conflict

Local input is preserved. The interface states whether data is cached, pending, rejected or requires comparison with a server version.

Reduced motion

All frames render directly in their final state. Progress meaning, save result and error recovery remain visible without travel, parallax, shimmer or celebration.

Reading order

Header → state summary → dominant content → supporting context → primary action → secondary content → navigation. Decorative media and placeholders are excluded.
